# Python Learning

This repository contains a collection of beginner-friendly Python examples and exercises that cover variables, strings, formatting, operators, and object-oriented concepts.

- [main.py](main.py) is the main entry script for quick Python output and learning examples.
- [Variable.py](Variable.py) explains how Python variables and data types are used in everyday code.
- [strings.py](strings.py) demonstrates how strings are created, combined, and used in simple Python programs.
- [EscapeCharacter.py](EscapeCharacter.py) shows how escape sequences help format and control text output in strings.
- [checkingIn.py](checkingIn.py) illustrates membership checks using the `in` operator with strings.
- [notin.py](notin.py) demonstrates how the `not in` operator checks whether a value is absent from a sequence.
- [operator_string.py](operator_string.py) covers string operators and common operations used with text values.
- [reverse_striing.py](reverse_striing.py) shows how to reverse a string in Python.
- [formatting.py](formatting.py) highlights string formatting and placeholder-based output patterns.
- [f-strings.py](f-strings.py) demonstrates the modern and readable way to format strings with f-strings.
- [strongTyped.py](strongTyped.py) introduces Python's dynamic typing and the idea of strong but not statically typed values.
- [fibonacci.py](fibonacci.py) implements the Fibonacci series using both a recursive function and an iterative loop.
- [nested_data.py](nested_data.py) stores a nested list of tuples (albums with their track listings) used as sample data for unpacking examples.
- [splitting_things.py](splitting_things.py) explores `split()` and `join()` for word frequency counting and parsing delimited strings.
- [UnpackingSequence.py](UnpackingSequence.py) demonstrates unpacking tuples and lists into variables, including nested tuple unpacking with `enumerate()`.
- [11_Sequence/list.py](11_Sequence/list.py) explains how lists work as ordered collections in Python.
- [11_Sequence/append.py](11_Sequence/append.py) demonstrates adding items to a list using the `append()` method.
- [11_Sequence/enumerate.py](11_Sequence/enumerate.py) shows how to iterate over list items with their index values.
- [11_Sequence/Sort.py](11_Sequence/Sort.py) covers sorting list data in ascending and descending order.
- [classes/Oops.py](classes/Oops.py) introduces a basic object-oriented example with a simple bank account class.
- [classes/composition_in_python.py](classes/composition_in_python.py) demonstrates composition and inheritance by building HTML tags with `Tag`, `DocType`, `Head`, and `Body` classes.
- [classes/MethodOverriding/main.py](classes/MethodOverriding/main.py) demonstrates how a program can use method overriding in class hierarchies.
- [classes/MethodOverriding/enemy.py](classes/MethodOverriding/enemy.py) defines an enemy class that is used to illustrate overridden behavior.
- [classes/MethodOverriding/player.py](classes/MethodOverriding/player.py) defines the player class used alongside the enemy class in the override example.
